# SwAIvyn Runtime Logs

This directory stores execution transcripts generated by `dev-run.ps1` and other development automation scripts. Each run writes a timestamped `dev-run-YYYYMMDD-HHMMSS.log` file so you can review the exact startup sequence, health checks, and any captured Docker diagnostics.

Log files are git-ignored automatically. If you need to share a log when troubleshooting, copy the relevant file out of this folder before attaching it to an issue or support request.
